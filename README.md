# Presentasi Penelitian 3D — EduAI

## Struktur
- index.html : seluruh 10 slide
- style.css  : desain, responsive layout, 3D/neon effects
- script.js  : navigasi, fullscreen, overview, keyboard/swipe, ADDIE interaction
- img/people : foto mahasiswa dan dosen
- img/illustrations : ilustrasi tambahan
- assets : asset pendukung

## Menjalankan
Cara paling mudah:
1. Extract folder.
2. Buka `index.html` di Chrome/Edge.

Untuk development, gunakan VS Code + Live Server jika tersedia.

## Mengganti foto
Buka `img/people/`, ganti placeholder dengan foto asli.
Kemudian sesuaikan nama file pada `index.html`.

## Navigasi
- Arrow Left / Right
- PageUp / PageDown
- Space = next
- Home / End
- F = fullscreen
- Tombol overview = melihat semua slide
- Swipe kiri/kanan di mobile
